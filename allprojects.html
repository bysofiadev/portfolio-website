Lumio Studio

Lumio Studio is a landing page for a fictional digital content agency, built from scratch with HTML, CSS and vanilla JavaScript. This project challenged me to create a polished, production-quality layout without frameworks — implementing dark/light mode with CSS custom properties, infinite CSS carousels, fluid typography with clamp(), and a fully responsive layout across mobile, tablet and desktop.
